# 《中国：毛的遗产》简体中文补丁

适配 **Steam Windows 版 1.8.5，Build 21377206**。中文使用游戏的英语语言槽。补丁由玩家电脑上的 Steam 原件构建，沿用原游戏的场景跳转、计分、存档和成就逻辑。

## 安装与还原

安装 Steam 游戏后，退出游戏。普通玩家直接运行本游戏的 Windows 安装程序。若使用源码并已安装 64 位 Python 3.11 或更高版本，可在源码根目录执行下列命令。

```powershell
py -3 games/mao/patch.py install
py -3 games/mao/patch.py verify
py -3 games/mao/patch.py restore
```

第一条安装中文，第二条核验当前补丁，第三条恢复安装前的文件。工具会在 Steam 主库及其他库目录查找游戏。若需手动指定，可在命令末尾加 `--game-data "D:\Games\Mao's Legacy\China_Data"`。如果系统使用 `python` 启动 Python，可将命令中的 `py -3` 替换为 `python`。

首次安装从固定的上游提交获取约 159 MiB 社区素材，逐文件验证 SHA-256。已下载并校验的文件会保留，网络中断后可再次安装。完整 Windows 安装包包含 UnityPy 1.25.4 及 Mono.Cecil 0.11.6，构建时使用 Windows 的 .NET Framework 编译器。缓存齐全后可断网安装；源码命令可加 `--offline` 以强制仅使用缓存。核验、还原和已安装同版的重复安装均可离线进行。原件保存在游戏安装目录的 `.nostalgames-zh-cn/backup/original`。缓存默认位于 `%LOCALAPPDATA%\Nostalgames-ZhCN\Mao`，可用 `--cache` 改变位置。

启动后先进入中文图形设置，再进入游戏。如界面为俄语，从主菜单打开“设置”（Настройки），点击设置页上方右侧的“简体中文”，再按左上角的返回箭头。左侧的“Русский”可切回俄语。Steam 更新或完整性验证可能恢复游戏文件。如果版本仍匹配，重新运行安装命令即可。

## 文本与界面

- 翻译开场图形设置、画质和帧率选项，缩短警告文案。主菜单、教程、外交、政党、储备和科研界面使用中文显示，内部场景标识保留原值。
- 回译和校对国家、政治人物、派系、政策纲领和修正说明。例子包括“汪东兴”“叶剑英”“陈锡联”“中国国民党革命委员会”。补回寡头效果说明遗漏的生活水平和情报网两项数值。
- 为法国剧本补充原英文资源中缺失的政党表和资源索引。按同版本俄语底表校正法国姓名与 25 项人物特质，保留法语人名的通行译名。
- 将中文黑体写入九个原有字体资源，对启动设置的常规文字与按钮分别使用常规和半粗字重。在五个长文本排版入口按中西文字宽、标点与富文本标记预排换行。经济页统一预算卡片字号，给腐败和储备说明增加行距。储备数字按显示精度取整，实际游戏计算保留原值。

本轮复核另外纠正了新疆结局错列、外交路线条件、朝鲜战后国名及脚本查询键。逐类结果、复核命令和人工审读范围见[文本复核记录](AUDIT.md)。

1.2.2 给事件标题、政治人物任命按钮及读档详情留出上下边距。总览页的进出口、国家局势和统一指标补全中文，带颜色的长提示按可见字符换行。存档成就状态改用深色文字。[本轮实机与文本复查](COMMUNITY-1.2.2.md)

1.2.4 补齐法国剧本六起事件，以及此前缺少的外交行动和条件。中国外交页恢复相应的联盟提示，德国统一、科研和政治路线的数值与措辞按实际界面校对。公民页的资助、特赦和政治追查提示也已汉化。内置教程重新校订 31 段讲解，并在英语槽的 22 张截图中就地标出中文操作名称。[全量资源与本版校订](COMMUNITY-1.2.4.md)

1.2.3 补全《雷锋的遗产》的公民创建、职业与性格、三份公民结局档案，以及基础游戏的两个失败结局标题。通过源码安装时，依赖准备完成后能正常接续安装。[公民与结局文本复查](COMMUNITY-1.2.3.md)

1.2.1 为设置页的两种语言标明名称，将音乐列表里原先挤成两行的五个曲名排回单行。存读档详情同步修正政体、游戏日期和成就状态，安装器也会核验还原备份。[社区反馈与本版复测](COMMUNITY-1.2.1.md)

## 已做的检查

构建程序校验原始文件和下载内容的 SHA-256，重新读取每个生成的 Unity 资源并逐对象比对。程序集检查覆盖 3,511 个原方法和 478,612 条原始 IL 指令，核对翻译引用、五个排版入口及两处储备数值显示。重复安装、校验、还原与再次安装已在独立目录演练。

首次发行版的实机抽查覆盖启动图形设置、新游戏、地图、悬停生活水平变化和经济页。各 DLC 分支、全部结局、所有显示分辨率及用户已有存档仍缺少逐项实测。部分历史照片、旗帜中的题字沿用原图。该补丁只支持列明的 Steam 文件指纹。
